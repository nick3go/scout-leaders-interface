This project was created for our closed scout leaders group as a helping tool.
It offers a variaty of features we found ourselves needing:
- loging previous scout meetings with our patrol
- reviewing past logs (offers various filters and search, useful for other patrol leaders)
- keeping a list of patrol meeting suggestions (we have one shared list where we all post, also offers various filters)
- offering or asking for help with certain knowladges as we are not all strong in the same areas
- it also has administration page built in where you can edit current patrols and their leaders

The project is build with next.js (for more info refer to 'README-next_js.md').
The backend is handled with Supabase (various entities for patrols, leaders, previous meetings, ideas, offered and searched knwoladges...).
The hosting is handled by Vercel.
